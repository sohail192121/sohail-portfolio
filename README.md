# Public project collection

This repository contains the portfolio and ten project prototypes temporarily hosted under `projects/`. GitHub blocked further repository creation after the first ten repositories with “You have created too many repositories, too quickly.” The other eight projects have standalone repositories. Every project is public and linked from the profile and portfolio. Dedicated repositories for the ten bundled projects are pending that GitHub restriction.

Run the website with `python -m http.server 8765`. Each bundled project has its own README with run commands, limitations and roadmap. The collection verification workflow executes their tests. No prototype is presented as a finished production system.
